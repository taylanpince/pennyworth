# Engineer

This agent is an assignment target only. Paperclip never runs it (its wake-ups are disabled).

Tasks assigned to Engineer, or labelled `engineer`, are executed by **pennyworth-runner** on the user's machine: Codex or OpenRouter, in a dedicated git worktree, with read-only GitHub access and no pushes unless the user comments `push` or `pr`. See README › Coding jobs.

If you are reading this inside a run, something is misconfigured. Do nothing, and set the task you were given back to `todo` with a comment saying so.
